Linear Algebra: The Muscle

A compressed, zero-fluff reference guide for the mathematical foundation of AI data structures.

Vectors (Data)

Definition: A 1D array of numbers. Represents a point in conceptual space (an Embedding).

Syntax (Python): x = np.array([1, 2, 3])

Matrices (Transformations)

Definition: A 2D grid of numbers. Represents an action that transforms a vector (stretching, rotating, projecting).

Syntax (Python): W = np.array([[1, 2], [3, 4]])

Dot Product (Similarity)

Definition: a · b = Σ(a_i * b_i). Measures how aligned two vectors are. High = similar concepts. Low/Zero = orthogonal/unrelated concepts.

Syntax (Python): np.dot(a, b) or a @ b

Matrix Multiplication (Forward Pass)

Definition: y = W @ x. Pushing data through a transformation layer. Composes multiple dot products simultaneously.

Syntax (Python): y = W @ x

Tensors

Definition: N-dimensional generalizations.
0D = Scalar
1D = Vector
2D = Matrix
3D = Image (H, W, Channels)
4D = Batch of Images
